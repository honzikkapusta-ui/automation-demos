Tohle dělám dobře. Zbytek je potenciální budoucí rozsah — žádné sliby.

Čištění CSV / Excel dat

Nečistý export → čistý vstup pro účetnictví, BI, CRM. Odstranění duplicit, normalizace názvů, měn, množství. 9 testů pokrývajících edge-casy.

Excel reporty z Pythonu

Multi-sheet workbooks s formulami, pivot tabulkami (SUMIFS/COUNTIFS), KPI dashboard a grafy. Žádné VBA, žádné ruční formátování. 7 testů.

Monthly Sales Report (Excel)

16 záznamů vygenerovaných Pythonem. Ukazuje opakovatelné vytváření reportů; žádný klientský výsledek nebo naměřená úspora.

Before (manuálně)

Copy CSV do Excelu
Insert sloupec G, =E2*F2, protáhnout
Data → PivotTable → táhnout Category do Values
Formátovat jako měna, přidat total row
Insert → Chart → Bar → formátovat barvy
Kopírovat graf do "Dashboard" listu
KPI vzorce psát ručně
Uložit, poslat mailem

After (skript)

python excel_builder.py

Otevře monthly_sales_report.xlsx:
Sheet "Sales Data"    - 16 řádků, auto-filter, revenue formula
Sheet "By Category"   - SUMIFS/COUNTIFS souhrny, totals
Sheet "Dashboard"     - 4 KPI karty + živý bar chart
Přepočet vzorců vyžaduje kompatibilní tabulkový procesor

Demo používá vložená syntetická data. Přizpůsobení skutečného exportu vyžaduje dohodu na mapování vstupů a validaci.

Jak spolupracujeme

Bez byrokracie. Funguje to takhle:

1. Pošleš mi soubor

CSV, Excel nebo odkaz na Google Sheets. Žádná hesla ani přístupové údaje neposílej.

2. Postavím pipeline

Python skript, testy, dokumentace. Dostaneš kód.

3. Spustíš to (nebo já)

Skript spuštěný lokálně. Žádný server.

4. Změny

Změní se formát dat? Nový sloupec? Domluvíme se, co a jak upravit.
